# マッスルサイザー

筋トレの動きを音に変える装置です。運動を楽しく続けられるようにすることを目的に、大学の演習（2年前期ハッカソン、チーム開発）で作りました。

## 仕組み
- ダンベル：ジャイロセンサ（MPU9250）で持ち上げる角度を測り、5段階の音階（C4〜G4）に変換する
- 腕立て伏せ：超音波距離センサで胸と床の距離を測り、5段階の音階に変換する
- センサ側のArduinoが音階をシリアル通信で音源側のArduinoに送り、音源側がFM変調と倍音合成で音を作ってDACから出力する（外部の音源ソフトは使わない）

## ファイル
| フォルダ | 内容 |
|---|---|
| `ksk_senser/` | ジャイロセンサ側（角度の測定と音階への変換） |
| `ksk_efect/` | ダンベル用の音源（トランペット風の音） |
| `dis_senser/` | 距離センサ側（距離の測定と音階への変換） |
| `dis_efect/` | 腕立て伏せ用の音源（ピアノ風の音） |
| `p_practice_2/` | Processingの練習用スケッチ |

## 使用技術
- Arduino（C/C++）、Processing（Java）
- FspTimer（タイマー割り込み）、SoftwareSerial、Wire、MPU9250_asukiaaa、Arduino_LED_Matrix

## 評価
60名規模の主観評価で、生成した音の自然さは5段階で平均3.25でした。
